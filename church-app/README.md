# Transcendent Life in Christ — church app

Design and planning material for the church's mobile app. Everything here is a
design mockup with demo data; it is not a working app.

## design/
| File | What it is |
| --- | --- |
| `TLC-App-Two-Themes.zip` | **Current app design.** 24 screens in both themes (Royal Night and Glory Light), side-by-side sheet, sitemap, brand files, developer theme spec |
| `TLC-Super-Admin-Console.zip` | Super admin console: 11 desktop screens in both themes |
| `earlier-versions/` | First drafts of each theme on its own (superseded by the two-themes package) |

## planning/
| File | Audience |
| --- | --- |

| `Church-App-Brief-for-Pastor.pdf` | The founder and leadership |
| `Church-App-Feature-Workbook-for-Team.pdf` | The team: choose which features the church needs |
